# Mario 任务助手

一个基于 Android 无障碍服务的个人任务助手，用于在本人设备上自动执行「每日签到名单」「蚂蚁森林」与「起点读书福利中心」的可识别日常任务。项目以小步验证的方式开发：每一步适配都以真机证据为准，不确定的环节如实标注，不夸大可靠性。

> ⚠️ 本项目仅用于个人设备上减少重复性手动操作。应用不含 INTERNET 权限，不联网、不上传任何数据。

## 功能

### 一键自动化（每日例行串联）
- 顶部「自动化」按钮一键串跑：每日签到 → 起点任务 → 森林任务 → 森林能量，前一个收尾后自动接续，前台服务保持到链尾
- 各任务仍保留单独运行入口；运行中按「停止运行」或切换其他任务会清空整个队列
- 单个环节失败不拖垮整条链：签到名单里某个 APP 失败跳过继续；起点/支付宝未安装时如实跳过该环节

### 每日签到（名单 APP 自动签到）
- 按注册表名单逐个打开 APP 并签到，当前名单：
  - **RQrun**：首页「签到福利」入口 → 签到页
  - **E充站**（cn.charge，依威能源；用户口述「E充电」实为此 App）：弹窗有「立即签到」就直接点；没有弹窗走首页右上角「签到」，签到页点日历里的「今天」格完成
  - **比亚迪**：进「我的」→ 右上角「签到」→ 签到页
  - **比亚迪**：进「我的」→ 右上角「签到」→ 签到页
- 新增 APP 只需在 `CheckinApps` 注册表加一条规格（包名/入口路径），运行器复用同一套状态机
- 入口与按钮全部精确文案 + 几何带 + 唯一候选 + 双帧稳定才点击；同屏推广按钮一概不碰
- 认「已签到/签到成功/明日再来/明天再来」完成标记，并容忍 OCR 形近字（如「签到戌功」）；已签到的 APP 直接记「今日已签到」
- 右上角入口容忍按钮图标被 OCR 成前缀（如「6签到」），闸门仍校验规范文案「签到」
- 单个 APP 预算 60 秒，点过入口进入签到页后再单独给 45 秒（慢 webview）；未安装/打不开/找不到入口/超时都记录原因后跳过，收尾汇总「完成 N，未确认 N，跳过 N」

### 蚂蚁森林 · 森林任务（做任务领奖励）
- 动态解析奖励弹窗任务行（不硬编码任务名，按 CTA 文案定位行、按几何关系取左侧标题），逐条"浏览 15 秒 → 返回 → 立即领取"
- 任务按钮按语义分类而不是精确文案白名单：进入型（逛一逛/去看看/去完成/去守护/去参加/马上玩）、领取型（立即领取/去领取）、抽奖型（去抽奖/立即抽奖）；遇到"去下单/去购买/去支付"一律跳过
- 浏览后行变"立即领取"会自动二次领取；行变"去抽奖"则直接进抽奖流程（OCR"立即抽奖 → 收下奖励"），抽完继续下一条
- 「今日累计奖励」的三个里程碑（`+40g/+60g/+100g立即领取`）会优先领掉——它们在无障碍树里是奖励与按钮拼在一起的单节点，做满任务后不会自动入账
- 已经被记成"完成/未确认"的行，一旦重新出现领取或抽奖入口会自动解除结论再执行一次，避免"任务做完了奖励一直没领"
- 落在第三方应用（淘宝/美团/一淘等）停留 15 秒后返回；应用商店/下载页直接返回并跳过
- 收尾按"自动识别"而不是点击次数：没有未处理的可执行行 + 页面签名两帧一致 + 已滑到底才停止；100 次点击仅作安全网
- 收尾时区分"完成 N 项"与"未确认 N 项"，未确认的会列出标题，不再笼统报"请核对奖励"
- 停错页面（森林主页/兑换页/1v1 挑战页）时会自动点「领奖」重开奖励弹窗，不会一直空转

### 蚂蚁森林 · 森林能量（收能量）
- 先收自己树上/边上成熟的能量气泡（只认树冠区域内的"数字+g"，避开右上总能量、右下 PK 进度、左上计数与底部广场卡片）
- 再进"找能量"逐个好友收取：识别"一键收"点击（同一位最多两次，覆盖"有些好友有两批能量"），然后上滑切下一位，循环
- 连续 3 位好友没有可收能量、或走完 30 位好友、或 10 分钟超时即收尾；点到的若不是能量气泡（跳到推广页）会自动返回并重新定位

### 起点读书 · 福利中心（全自动链路）
- 启动起点 → 自动点击底部"我的"标签 → 进入"福利中心"
- 页面找不到任务行时自动向上滑动（每个方向最多 6 次）；滑到页面底部仍无任务行时自动反向回扫，覆盖起点恢复在福利中心底部的场景
- 福利中心按多锚点识别（标题栏/任务区/限时福利/底部兑换区任一可见即可），不依赖滚出屏幕的"福利中心"标题
- 按优先级匹配任务行（当前已确认）：`【限时】广告·加点！` → `激励任务` → `完成3个广告任务得奖励` → `去携程签到领积分`
- 点击"去完成"进入广告页，以广告平台披露行"进入详情页或第三方应用"为锚点（视频播放态回落到右下角"广告"标识），按几何定位底部按钮，按钮文案不限（已实测覆盖：查看详情 / 去逛逛 / 立即抢购 / 去看看 / 领取优惠）
- 双模式落地页：第三方应用（停留 15 秒后自动切回起点）／ 起点内 WebView（停留 15 秒后按返回键退出）
- 激励视频轮播：识别"已完成第N个任务 滑动继续完成"后自动左滑进入下一支广告，每支都重新走 浏览入口 → 15 秒 → 返回；识别"恭喜完成任务"后点右上角关闭，并关闭"知道了"奖励弹窗
- 阅读解锁：打开书架第一本书阅读 2 分钟后返回，重置导航标记并直接重走 `我` → `福利中心`，不再滚动书架页
- 携程签到：滚动到"限时福利"区的`去携程签到领积分`，按钮按几何定位（标题右侧唯一短标签，不依赖 OCR 文案）；进入签到页后只点`立即签到`（去移动/升级赚积分等推广按钮一概不碰），随后切回起点核对"领奖励/已领取"状态
- 全部任务完成后自动收尾：携程行显示`已领取`时连续两帧确认即停止，不再滑动空等超时

## 安全边界

- **按钮黑名单**：OCR 明确识别为"下载 / 安装"类按钮一律拒绝并停止；抢购、支付等文案不再按文案拦截，因为点击只会打开落地页，且落地页内不做任何点击、不会产生订单
- **每日签到只认精确文案**：CHECKIN 闸门只允许「签到 / 立即签到 / 去签到 / 签到福利」与日历签到格的「今天」，「签到领红包」等同屏推广与交易类文案一律拒绝；完成标记只读不点
- **落地页内不做任何点击**：进入广告落地页后仅停留计时，不与页面交互，不会产生订单
- **截图仅存内存**：`takeScreenshot` 结果在设备内存中转成位图做 OCR，用完即释放；应用无 INTERNET 权限（Manifest 中显式移除），数据不可能离开设备
- **锚点防误点**：广告按钮的定位以平台固定披露行（容忍已知单字 OCR 误读）+ 几何带（居中、间距、行高）双重校验，连续两帧稳定后才点击
- **不确定即停止**：页面不可识别、按钮歧义、落地页异常时如实报告并停止，不猜测操作

## 技术实现

- 纯 Java + Android 无障碍 API，无第三方框架
- 界面为 NES 像素风：金币、马里奥、蘑菇等图标由字符矩阵实时渲染成 Bitmap（无图片资源），启动图标为「马里奥仰望金币」像素画
- ML Kit 中文离线 OCR（`text-recognition-chinese`），识别结果仅与内置规则比对
- 流程逻辑运行在独立工作线程（`HandlerThread`），与主线程解耦——实测 HyperOS/Android 16 上主线程会不可预期地静默停摆
- 试运行期间启动前台服务（`specialUse` 类型）并附带实时状态通知；实测 MIUI 的 MI Daemon 会绕过 AOSP 直接通过 cgroup v2 冻结后台进程（`/sys/fs/cgroup/.../cgroup.freeze`），前台服务是有效的豁免手段
- 关键判定逻辑（匹配器、策略、状态机）为纯 JVM 类，配套 JUnit 单元测试

## 构建与安装

```bash
# 单元测试
./gradlew testDebugUnitTest

# 构建 debug APK
./gradlew assembleDebug

# 安装到已连接设备
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- minSdk 26 / targetSdk 36
- 安装后需在系统设置中开启无障碍服务「Mario」
- Android 13+ 首次启动会申请通知权限（前台服务状态通知需要）

## 使用

打开应用，按提示开启无障碍服务后：

> 执行「起点任务」「每日签到」「自动化」前，还需在 设置 → 应用管理 → Mario → 其他权限 中开启「后台弹出界面」与「显示悬浮窗」。缺少任一权限时，Android 会静默拦截从后台启动目标应用（logcat：`Abort background activity starts`），广告页无法自动切回。

- **自动化** — 一键串跑：每日签到 → 起点任务 → 森林任务 → 森林能量；与「出发前检查」并排置于顶部一行
- **每日签到** — 按名单逐个打开 RQrun / E充站 / 比亚迪 自动签到，失败跳过继续
- **森林任务** — 启动支付宝并进入森林执行领取（需停在奖励弹窗；自动化链路中会自动唤起并恢复）
- **森林能量** — 收自己树上的能量，再进"找能量"逐个好友一键收
- **起点任务** — 启动起点并全自动执行上述链路
- **停止运行** — 随时终止当前流程（自动化队列一并清空）
- **出发前检查** — HyperOS 防冻结清单（弹窗展示），与「自动化」并排

运行期间请勿将应用从最近任务中划掉（会杀死进程、终止试运行）；通知栏会实时显示流程状态。
