# Mario 任务助手

一个基于 Android 无障碍服务的个人任务助手，用于在本人设备上自动执行「蚂蚁森林」与「起点读书福利中心」的可识别日常任务。项目以小步验证的方式开发：每一步适配都以真机证据为准，不确定的环节如实标注，不夸大可靠性。

> ⚠️ 本项目仅用于个人设备上减少重复性手动操作。应用不含 INTERNET 权限，不联网、不上传任何数据。

## 功能

### 蚂蚁森林
- 试运行"领取森林浏览任务"：仅当页面出现已验证任务（逛支付宝会员中心 / 逛一逛芝麻攒粒攻略）的可点击"立即领取"按钮时执行领取。

### 起点读书 · 福利中心（全自动链路）
- 启动起点 → 自动点击底部"我的"标签 → 进入"福利中心"
- 页面找不到任务行时自动向上滑动（每个方向最多 6 次）；滑到页面底部仍无任务行时自动反向回扫，覆盖起点恢复在福利中心底部的场景
- 福利中心按多锚点识别（标题栏/任务区/限时福利/底部兑换区任一可见即可），不依赖滚出屏幕的"福利中心"标题
- 按优先级匹配任务行（当前已确认）：`【限时】广告·加点！` → `激励任务` → `完成3个广告任务得奖励` → `去携程签到领积分`
- 点击"去完成"进入广告页，以广告平台披露行"进入详情页或第三方应用"为锚点（视频播放态回落到右下角"广告"标识），按几何定位底部按钮，按钮文案不限（已实测覆盖：查看详情 / 去逛逛 / 立即抢购 / 去看看 / 领取优惠）
- 双模式落地页：第三方应用（停留 15 秒后自动切回起点）／ 起点内 WebView（停留 15 秒后按返回键退出）
- 激励视频轮播：识别"已完成第N个任务 滑动继续完成"后自动左滑进入下一支广告，每支都重新走 浏览入口 → 15 秒 → 返回；识别"恭喜完成任务"后点右上角关闭，并关闭"知道了"奖励弹窗
- 阅读解锁：打开书架第一本书阅读 2 分钟后返回，重置导航标记并直接重走 `我` → `福利中心`，不再滚动书架页
- 携程签到：滚动到"限时福利"区的`去携程签到领积分`，按钮按几何定位（标题右侧唯一短标签，不依赖 OCR 文案）；进入签到页后只点`立即签到`（去移动/升级赚积分等推广按钮一概不碰），随后切回起点核对"领奖励/已领取"状态
- 全部任务完成后自动收尾：携程行显示`已领取`时连续两帧确认即停止，不再滑动空等超时

## 安全边界

- **按钮黑名单**：OCR 明确识别为"下载 / 安装"类按钮一律拒绝并停止；抢购、支付等文案不再按文案拦截，因为点击只会打开落地页，且落地页内不做任何点击、不会产生订单
- **落地页内不做任何点击**：进入广告落地页后仅停留计时，不与页面交互，不会产生订单
- **截图仅存内存**：`takeScreenshot` 结果在设备内存中转成位图做 OCR，用完即释放；应用无 INTERNET 权限（Manifest 中显式移除），数据不可能离开设备
- **锚点防误点**：广告按钮的定位以平台固定披露行（容忍已知单字 OCR 误读）+ 几何带（居中、间距、行高）双重校验，连续两帧稳定后才点击
- **不确定即停止**：页面不可识别、按钮歧义、落地页异常时如实报告并停止，不猜测操作

## 技术实现

- 纯 Java + Android 无障碍 API，无第三方框架
- 界面为 NES 像素风：金币、马里奥、蘑菇等图标由字符矩阵实时渲染成 Bitmap（无图片资源），启动图标为「马里奥仰望金币」像素画
- ML Kit 中文离线 OCR（`text-recognition-chinese`），识别结果仅与内置规则比对
- 流程逻辑运行在独立工作线程（`HandlerThread`），与主线程解耦——实测 HyperOS/Android 16 上主线程会不可预期地静默停摆
- 试运行期间启动前台服务（`specialUse` 类型）并附带实时状态通知；实测 MIUI 的 MI Daemon 会绕过 AOSP 直接通过 cgroup v2 冻结后台进程（`/sys/fs/cgroup/.../cgroup.freeze`），前台服务是有效的豁免手段
- 关键判定逻辑（匹配器、策略、状态机）为纯 JVM 类，配套 JUnit 单元测试

## 构建与安装

```bash
# 单元测试
./gradlew testDebugUnitTest

# 构建 debug APK
./gradlew assembleDebug

# 安装到已连接设备
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- minSdk 26 / targetSdk 36
- 安装后需在系统设置中开启无障碍服务「Mario」
- Android 13+ 首次启动会申请通知权限（前台服务状态通知需要）

## 使用

打开应用，按提示开启无障碍服务后：

> 执行「起点任务」前，还需在 设置 → 应用管理 → Mario → 其他权限 中开启「后台弹出界面」与「显示悬浮窗」。缺少任一权限时，Android 会静默拦截从后台启动起点（logcat：`Abort background activity starts`），广告页无法自动切回。

- **森林任务** — 启动支付宝并进入森林执行领取
- **起点任务** — 启动起点并全自动执行上述链路
- **停止运行** — 随时终止当前流程
- **出发前检查（防冻结）** — HyperOS 防冻结清单（弹窗展示）

运行期间请勿将应用从最近任务中划掉（会杀死进程、终止试运行）；通知栏会实时显示流程状态。
