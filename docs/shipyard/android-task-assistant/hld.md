## 目的与成功标准

在小米 15、Android 16 上运行独立 App，分别处理支付宝蚂蚁森林能量和任务、蚂蚁庄园饲料、芭芭农场领取、起点读书任务。可单独启停、手动运行并查看每项结果；具体任务以真机实际页面可识别且可验证为准。

## 前提、约束和假设

- 用户提供了目标手机、安卓版本、四类任务和部分截图；截图并未覆盖全部流程。
- 工作目录目前为空，未发现 adb 或已配置的 Android SDK；需要补齐开发环境并连接真机才能验证。
- 页面可能更新、控件不可访问或要求人工验证，不能保证全部任务自动完成。定时执行受系统后台限制影响。

## 使用方式与边界

用户安装 App、手动启用无障碍服务、登录目标 App，选择任务后启动或设置执行时间。涉及支付、下单、订阅、授权、分享邀请、验证码及其他不可确定的操作时暂停并提示，不替用户确认。截图中的旧衣回收下单属于此类。用户于 2026-11-08 明确要求浏览广告任务，纳入支持范围；仅按页面正常流程观看并验证结果，不绕过广告或验证；失败时记录并退出。抽奖仅在明确免费且无需额外授权时尝试，支付或条件不明时暂停。

## 设计决策

<a id="hld-1"></a>

### [x] 1. 运行方式
- 结论：原生独立安卓 App，通过无障碍服务执行界面操作，不依赖 root 或电脑常驻。
- 依据：用户明确选择独立 App；无障碍服务是可行的普通应用操作路径。

<a id="hld-2"></a>

### [x] 2. 任务模块
- 结论：森林、庄园、农场和起点分别配置和运行；先覆盖可识别的领取、签到及普通浏览任务，具体动作以实机结果为准。
- 依据：用户要求单独处理四类任务；缺少其他页面和完整流程。

<a id="hld-3"></a>

### [x] 3. 安全边界
- 结论：敏感动作暂停，用户本人处理；不读取或保存密码、支付信息，不绕过验证码或风控。
- 依据：任务包含下单等潜在额外后果，按最小必要操作设计。

<a id="hld-4"></a>

### [x] 4. 调度和记录
- 结论：支持手动和尽力定时执行、停止、结果记录；锁屏、系统省电或权限不足时明确提示，不能保证准时运行。
- 依据：移动系统限制以及用户自动化目标。

<a id="hld-5"></a>

### [x] 5. 识别策略
- 结论：优先无障碍节点和页面状态校验；不可访问的画面可评估截图识别，但须经过真机验证和独立授权；不凭截图固定坐标宣称可靠。
- 依据：给定截图无法证明目标控件暴露在无障碍树中。

## 模块与数据概览

App 界面管理任务开关、启动/停止、调度和日志；无障碍执行器根据当前应用和页面状态运行各任务模块，向本地记录结果。设置与日志只保存在本机；无需服务器。目标应用没有可依赖的公开接口，具体入口和页面契约待实机核验。
