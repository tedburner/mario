# 安卓任务助手 · 详细设计

> 状态：详细设计 · 有效设计点已解决 5 / 5

## 操作与任务

<a id="lld-1"></a>

### [x] 1. 控制界面
- 回链：[hld #1](hld.md#hld-1)、[hld #2](hld.md#hld-2)
- 四个任务各有开关、单独运行入口与最近结果；提供全部运行和停止。显示无障碍权限状态及系统设置入口。

<a id="lld-2"></a>

### [x] 2. 执行器
- 回链：[hld #2](hld.md#hld-2)、[hld #5](hld.md#hld-5)
- 单次仅运行一个任务，有限次数重试与超时；每步检查目标包名、页面和可点击节点，操作后确认状态变化。无法确定目标、出现陌生页面或敏感操作时停下并记录原因；停止操作中断队列。
- 四个模块独立定义入口、页面状态和可处理动作。上线前按真机页面确认每一动作；不把未验证流程标记为支持。

<a id="lld-3"></a>

### [x] 3. 敏感动作及广告
- 回链：[hld #3](hld.md#hld-3)
- 禁止自动确认付款、下单、订阅、授权、邀请分享、验证码和账户安全操作。用户明确要求广告任务：正常播放并等待完成，不绕过验证；超时或无法验证则记录未完成。抽奖仅在明确免费且无需额外授权时尝试。

## 调度、存储和验证

<a id="lld-4"></a>

### [x] 4. 调度及结果
- 回链：[hld #4](hld.md#hld-4)
- 本地保存任务配置、可选运行时间及有限的结果日志；显示成功、跳过、失败和需要人工处理。定时采用系统支持的后台调度，具体触发精度及锁屏行为以设备实测为准；权限、网络、锁屏等条件不满足时告知用户。

<a id="lld-5"></a>

### [x] 5. 验证
- 回链：[hld #1](hld.md#hld-1)、[hld #2](hld.md#hld-2)、[hld #5](hld.md#hld-5)
- 构建 APK 并检查基本逻辑；在小米 15 实测权限、每个页面的识别、任务结果、异常退出及调度。若无法连接真机，明确列出未验证项目和需要用户提供的页面信息，不宣称四类任务可用。
